Source discipline

A claim about a data source is not documentation.

Blog posts. Answers from 2019. Colleagues. Assistants. Your own memory of last term.

Before you rely on code against a source, check against the vendor's current docs:

  1. Package — does it still exist under that name?
  2. Endpoint or table — in the current reference?
  3. Fields — do those columns exist?
  4. Coverage — does it hold your period?
  5. Licence — are you allowed to do this?

Nobody runs step 5. It is the only one that can cost your institution its access.

def total_return(p0, pt, dividends):
    """Total return over a holding period. Dividends assumed held in cash."""
    return (pt - p0 + sum(dividends)) / p0

That docstring records the convention — and settles the argument six weeks from now.
