Register: RULES. Conventions, integrity, and fallbacks. No teaching here — see handout.md.

The two lanes, and the guarantee

Generation 1 — institutional: WRDS, LSEG Workspace. Attempt required; access not required.

Generation 2 — API-native: SEC EDGAR, Financial Datasets, Databento, and others in the register.

Guaranteed lane: SEC EDGAR direct, yfinance, FRED. Every graded task in this course is completable here alone, at zero cost, with no account. A student working entirely in this lane can earn full marks on every assignment.

Not used: Bloomberg. Terminal-bound, unscriptable for coursework.

No graded task requires you to spend money

Free tiers and credits only. If a source demands payment before issuing a key, use another one.

If you choose to spend your own money on an optional enrichment, that is your decision and it earns you nothing in points.

Access outcomes are never graded; attempts are

A denied or pending account costs nothing. What is graded: the link used, the timestamp, the status evidence, the remaining blocker, and what you learned about what that platform is for.

The same applies to entitlements. An honest "I diagnosed it and the answer is still unclear" earns full marks — that is the state the instructor is in.

Verify source facts before you rely on code

Before relying on any code against a data source — written by you, found online, or generated — check it against the vendor's current documentation: package name, endpoint or table, field names, coverage window, and licence.

Recording that you checked is part of the deliverable. "It worked" is not a verification; code can run against the wrong field and return plausible numbers.

A statement about a source is a claim, not documentation, whatever its source.

Licence compliance

Capital IQ and PitchBook licences restrict bulk export and scripted extraction. Do not write scrapers against them. Do not share exported data outside your submission.

Do not pool accounts or share credentials. WRDS and LSEG accounts are personal. Sharing one is an integrity violation, not a shortcut.

If an analysis seems to require bulk extraction from a restricted platform, the analysis is designed wrong for this course. Use WRDS, the Generation 2 sources, or the guaranteed lane.

Tools

Use whatever tools you like, including AI assistants. That is expected and needs no disclosure.

What must be yours: the framing of the problem, the choice of which source to ask, the judgment about which source is right, the adjudication of every discrepancy, and the explanation you could give under questioning. Those are the graded surfaces, and no tool produces them for you — deciding whether a difference is a defect or a convention requires knowing how securities trade.

You must be able to explain every line of code you submit. Where it came from is not a defence, and that has always been true of copied code.

Reproducibility

Every submitted notebook must run start to finish on a fresh kernel. A notebook that only works because of state left in memory is not a deliverable.

Every number in a write-up must be traceable to a line of code that produced it. Numbers typed in by hand are not sourced.

Never commit an API key. Use an environment variable or Colab's secrets. A key in a submitted notebook is a security incident, and you should rotate it immediately.

Citation of data

Every source used gets an entry in source_log.md: the source, the access route, the coverage window it actually serves, and the retrieval date.

Week 7 is graded on whether a colleague can reproduce your work. An uncited source makes that impossible.
